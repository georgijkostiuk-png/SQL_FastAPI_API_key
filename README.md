# SQL_FastAPI_API_key
Vacation Planner REST API (SQL/API project) — https://github.com/georgijkostiuk-png/SQL_FastAPI_API_key
REST backend (FastAPI + MySQL) for trip planning: users create trips, the API fetches live flight and hotel offers from Google Flights/Hotels (SerpApi) and stores them. Relational schema with SQLAlchemy ORM (one-to-many relations, cascade deletes), Pydantic request/response validation, repository-pattern CRUD layer, interactive Swagger/OpenAPI docs.
